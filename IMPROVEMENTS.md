# Сводка улучшений модели TradingCNN -> TradingLSTM

## Baseline (CNN, 50 эпох)

- Архитектура: Conv2d(1->64->128->256) + FC(768->700->64->2)
- Признаки: 4 (open, high, low, close)
- Порог сигнала: 200 пипсов
- batch_size: 32, shuffle=False
- Без Dropout, без BatchNorm
- **Train Loss: 0.551**
- **Val Accuracy: 0.643** (best 0.675)
- Val Accuracy нестабильна (осцилляции 0.47-0.67 между эпохами)
- F1-score не измерялся

## Финальная версия (LSTM, A+B+C, 30 эпох)

- Архитектура: BiLSTM(hidden=128, layers=2) + FC(256->128->64->2)
- Признаки: 12 (open, high, low, close, returns, body, upper_shadow, lower_shadow, ema_diff, rsi, atr, bb_position)
- Порог сигнала: 100 пипсов
- batch_size: 128, WeightedRandomSampler
- Dropout 0.4, BatchNorm на входе, label smoothing 0.1, gradient clipping 1.0
- **Train Loss: 0.122**
- **Val Accuracy: 0.720**
- **Val F1: 0.781** (best на эпохе 28)
- Кривые обучения стабильны

---

## Изменения по категориям

### A. Данные и признаки

| Изменение | Было | Стало | Эффект |
|-----------|------|-------|--------|
| Количество признаков | 4 (OHLC) | 12 (+returns, body, shadows, ema_diff, rsi, atr, bb_position) | Модель получила больше сигналов для классификации |
| Порог сигнала | 200 пипсов | 100 пипсов | Доля класса SIGNAL выросла, дисбаланс уменьшился |
| Технические индикаторы | нет | RSI(14), ATR(14), EMA(10/30), Bollinger Bands(20) | Модель видит тренд, волатильность, перекупленность |
| Производные фичи | нет | returns, body, upper/lower shadow | Нормализация + информация о структуре свечей |

### B. Архитектура

| Изменение | Было | Стало | Эффект |
|-----------|------|-------|--------|
| Тип модели | CNN (Conv2d x3) | BiLSTM (2 слоя) | Лучше моделирует временные зависимости |
| Направление | однонаправленный | bidirectional | LSTM видит контекст и вперёд, и назад |
| BatchNorm | нет (потом добавлен между conv) | на входе (BatchNorm1d) | Стабилизация входных данных |
| Dropout | нет (потом добавлен 0.3) | 0.4 | Уменьшение переобучения |
| FC слои | 768->700->64->2 | 256->128->64->2 | Меньше параметров, меньше переобучение |

### C. Стабилизация обучения

| Изменение | Было | Стало | Эффект |
|-----------|------|-------|--------|
| batch_size | 32 | 128 | Стабильнее градиенты, меньше осцилляций |
| Label smoothing | нет | 0.1 | Модель менее самоуверенна, лучше обобщает |
| Gradient clipping | нет | max_norm=1.0 | Защита от взрыва градиентов в LSTM |
| Early stopping | нет | patience=7 по F1 | Автоматическая остановка при переобучении |
| Балансировка батчей | class_weight='balanced' в loss | WeightedRandomSampler | Каждый батч содержит оба класса в равных пропорциях |
| LR scheduler | ReduceLROnPlateau(patience=5) | то же | Без изменений |

### D. Валидация

| Изменение | Было | Стало | Эффект |
|-----------|------|-------|--------|
| Shuffle в train | shuffle=True | shuffle=False + WeightedRandomSampler | Temporal integrity + балансировка |
| Метрики | только Accuracy | Accuracy + F1 (weighted) | F1 лучше отражает качество при дисбалансе |

## Сводная таблица результатов

| Метрика | Baseline CNN | A+B (LSTM) | A+B+C (LSTM+stab) | Улучшение |
|---------|-------------|------------|-------------------|-----------|
| Train Loss | 0.551 | 0.470 | **0.122** | -78% |
| Val Accuracy | 0.643 | 0.900* | **0.720** | +12% |
| Val F1 | не измерялся | не измерялся | **0.781** | — |
| Стабильность | осцилляции | 1 класс* | **стабильный рост** | — |

*A+B предсказывал только один класс (WAIT), accuracy = доля мажоритарного класса

## Ключевые выводы

1. **Самое важное изменение** — WeightedRandomSampler. Без него модель предсказывала только мажоритарный класс (WAIT) и показывала accuracy 0.90, которая не отражала реальное качество.

2. **LSTM vs CNN** — для временных рядов LSTM значительно эффективнее. Loss снизился в 4.5 раза при меньшем количестве эпох.

3. **Расширение признаков** — добавление технических индикаторов (RSI, ATR, EMA, BB) дало модели дополнительные сигналы, которые невозможно извлечь из сырых OHLC данных.

4. **F1 важнее Accuracy** — при дисбалансе классов accuracy вводит в заблуждение. F1-score 0.781 показывает, что модель действительно научилась различать оба класса.
